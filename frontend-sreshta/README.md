# TaxPal - Frontend

This is the frontend application for **TaxPal**, an internship project developed for Batch 4. It provides the user interface for the application and is built using Angular and TailwindCSS.

## Tech Stack
- **Angular**
- **TailwindCSS**
- **TypeScript**

## Setup Instructions

### 1. Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.
- Angular CLI installed globally (`npm install -g @angular/cli`).

### 2. Install Dependencies
Navigate to the `frontend` directory and install the required packages:
```bash
npm install
```

### 3. Run the Development Server
Start the Angular development server:
```bash
npm start
```
Navigate to `http://localhost:4200/` in your browser to view the application. The app will automatically reload if you change any of the source files.

### 4. Build for Production
To build the project for production, run:
```bash
npm run build
```
The build artifacts will be stored in the `dist/` directory.
