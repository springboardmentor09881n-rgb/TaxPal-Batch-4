# TaxPal

**TaxPal** is a comprehensive web application developed as an internship project by **Batch 4**. This repository contains both the frontend application and the backend API, functioning together as a complete full-stack solution.

## 🚀 Tech Stack (MEAN Stack)

### Frontend
- **Angular**
- **TailwindCSS**
- **TypeScript**

### Backend
- **Node.js & Express.js**
- **MongoDB & Mongoose**
- **JWT Authentication**

---

## 📁 Project Structure

This repository is organized into two main directories:

- [`/frontend`](./frontend/) - Contains the Angular client application.
- [`/backend`](./backend/) - Contains the Node.js/Express REST API.

---

## 🛠️ Getting Started

To run the project locally, you will need to start both the backend server and the frontend client. 

### 1. Start the Backend
For detailed instructions, see the [Backend README](./backend/README.md).
```bash
cd backend
npm install
npm run dev
```

### 2. Start the Frontend
For detailed instructions, see the [Frontend README](./frontend/README.md).
```bash
cd frontend
npm install
npm start
```
